# OYWW1000 参数用例（PARAM-*）

### PARAM-FUNC-001 每个 NTF_* 键 ON/OFF 返回 OK，getParam 一致
- **测试目的**：验证数据流开关。
- **流程与逻辑**：对适用键（`NTF_EMG`/`NTF_GEST`/`NTF_IMU`/`NTF_GFORCE_ACC`/`NTF_GFORCE_GYRO`/`NTF_GFORCE_EULER`/`NTF_GFORCE_QUAT`）逐一 `setParam("ON"/"OFF")`，`getParam("NTF")` 核对；`NTF_MAG_ANGLE`/`NTF_SPO2`/`NTF_PPG`/`NTF_PPG_RAW` 按 `getDeviceInfo()` 对应 `ChannelCount` 判定（>0 测，==0 记录“不适用，跳过”）。
- **预期结果**：返回 `OK`，`getParam` 状态一致。
- **有效性说明**：参数读写一致。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

### PARAM-FUNC-002 FILTER_* 键 ON/OFF
- **测试目的**：验证滤波开关（EMG 50/60Hz 工频陷波、高通/低通）。
- **流程与逻辑**：`setParam("FILTER_50HZ"/"FILTER_60HZ"/"FILTER_HPF"/"FILTER_LPF","ON"/"OFF")`，`getParam("FILTER")` 核对；设备不支持的键返回 `Error` 则记录“不支持”。
- **预期结果**：返回 `OK`，状态一致。
- **有效性说明**：滤波参数生效。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试
