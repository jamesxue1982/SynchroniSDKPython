# OYWW1000 电量/日志/调试用例（BATT-* / LOG-*）

## 电量（BATT-*）

### BATT-FUNC-001 getBatteryLevel 返回 0~100（或 -1）
- **测试目的**：验证电量读取。
- **流程与逻辑**：Ready 后调 `getBatteryLevel()`。
- **预期结果**：返回 0~100；无有效读数返回 -1（不判失败，仅记录）。
- **有效性说明**：电量接口可用。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

### BATT-FUNC-002 onPowerChanged 上报 0~100，±2% 滞回，不报 -1
- **测试目的**：验证电量回调。
- **流程与逻辑**：注册 `onPowerChanged`，观察上报值（可改变功耗/等待电量变化）。
- **预期结果**：上报 0~100，1% 抖动被过滤，不报 -1。
- **有效性说明**：回调稳定性。
- **可自动化**：semi-auto
- **人工介入**：人工制造电量变化或长时间观察。
- **测试结果**：待测试

### BATT-FUNC-003 powerRefreshInterval 决定上报周期
- **测试目的**：验证刷新周期。
- **流程与逻辑**：设不同 `powerRefreshInterval`，统计 `onPowerChanged` 周期。
- **预期结果**：周期与设置一致。
- **有效性说明**：周期参数生效。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

## 日志/调试（LOG-*）

### LOG-FUNC-001 setDebugEnabled 开关 controller log
- **测试目的**：验证调试日志。
- **流程与逻辑**：`setDebugEnabled(True/False)`，检查日志文件。
- **预期结果**：True 创建 log，False 关闭。
- **有效性说明**：日志开关。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

### LOG-FUNC-002 setLogPath 目录/已存在文件
- **测试目的**：验证日志路径。
- **流程与逻辑**：`setLogPath(True, dir)` 与指向已存在文件。
- **预期结果**：目录创建成功；已存在文件被拒绝。
- **有效性说明**：路径校验。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

### LOG-FUNC-003 DEBUG_LOG_PATH=True 生成 profile log
- **测试目的**：验证设备级日志。
- **流程与逻辑**：`setParam("DEBUG_LOG_PATH", True)`，`getParam("DEBUG_LOG_PATH")` 读路径，检查生成。
- **预期结果**：生成 profile log，路径可读。
- **有效性说明**：每设备日志。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

- **测试目的**：验证应用日志接口。
- **流程与逻辑**：`SensorController.log(...)`/`SensorProfile.log(...)`，level `D/I/W/E`，检查 `[App]` 标记与回退。
- **预期结果**：正确写入，带 `[App]` 标记；profile 未启用时回退 controller log。
- **有效性说明**：应用日志正确。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试
